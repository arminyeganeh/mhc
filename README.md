# Repository for Detecting and Mapping Manufactured Housing Communities
This repository contains the code scripts referenced in the Scientific Data journal article titled "Detecting and Mapping Manufactured Housing Communities" by Armin Yeganeh, Maria Marshall, and Noah Durst. The dataset described in this article is publicly available at Zenodo (doi: 10.5281/zenodo.15360489).
